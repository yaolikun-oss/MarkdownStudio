# Markdown Studio Visual 0.7.31 验证记录

日期：2026-10-22

## 本版范围

- 调整原生 macOS 版界面，不复制跨平台版界面。
- 保留 macOS 原生菜单、窗口、分栏和控件行为。
- 吸收跨平台版的界面分层：左侧功能轨、底部整体设置、按当前区域变化的顶部工具条、集中显示切换。
- 不改动阅读内容、Markdown 内容和 Windows 跨平台版源代码。

## 已完成检查

- `swift build`：通过。
- Universal Release 构建：通过，包含 `arm64` 与 `x86_64`。
- 严格代码签名校验：通过。
- DMG 校验：通过，`hdiutil verify` 返回 VALID。
- 版本号：`0.7.31`。
- 旧版设置迁移：从 0.7.30 优先导入，0.7.29 作为后备来源。
- 原生界面检查：
  - 左侧功能轨显示“文件 / 阅读 / Markdown / 网页收藏”，整体设置位于左下角。
  - 整体设置能在“阅读 / MD 可视化 / MD 源码”三套互不覆盖的设置间切换。
  - 阅读聚焦时顶部只显示阅读导航与阅读相关控制。
  - 当前区域只显示一个关闭按钮，提示会说明关闭对象及未保存处理。
  - 视图与工作区模式控制移到第二层布局栏，顶部工具条不再混排所有模式按钮。

## 检查中发现并修正

- 最近工作区同时打开 EPUB 与 Markdown 时，旧的 EPUB 状态标记可能导致“原文 / 笔记 / 并排”控制不出现。现改为根据阅读源和笔记是否实际同时存在判断。
- 没有打开内容时，隐藏宽度、字号、样式和视图布局控制，避免空白工作区出现不可用工具。

## 待最终界面复核

- 上述两项最后修正已经重新编译并打包。最终 CUA 界面复核因 Mac 自动锁屏暂时中断；解锁后需再次确认最近工作区的模式组、空白工作区和窄窗口显示。
