# Markdown Studio Visual 0.7.9 验证记录

日期：2026-10-16；构建号：51。样本均为自建文件，未修改用户正在编辑的笔记。

## 本次根因与修改

1. 可视化转换器曾把 `div` 中的文字、`strong`、`u` 分别用换行连接，并把顶层行内节点按段落连接；改为合并连续行内节点。渲染后 `br` 附带的 HTML 源码换行不再重复写回。组合加粗/斜体/下划线的样式分别保留。
2. SwiftUI 分栏的理想宽度和内容固有尺寸会重新分配宽度，宽度测量回调还会把这种结果保存。改为原生分栏拥有几何尺寸，关闭子 NSHostingView 的固有尺寸约束；仅用户结束拖动时保存尺寸。目录侧栏、阅读与笔记、普通 Markdown 分栏统一使用 5pt 分隔带与中央握柄，鼠标命中范围 14pt，光标为左右双箭头。
3. 旧定位只同步可见段落行号，源码初始化又会写回旧选择位置。现在以当前文档的 UTF-16 字符位置映射 DOM 和源码的选择范围，另外保存文字在视口中的位置；初始化恢复期间抑制位置反馈，未操作的往返保留同一锚点。
4. 阅读＋笔记布局中的窗口模式不代表实际编辑目标。格式快捷键增加真实焦点判断，可视化 focusin 更新目标，隐藏源码不接收格式命令。切进源码后恢复键盘焦点。
