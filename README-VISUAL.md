# Markdown Studio Visual 0.7.31

以跨平台版更清晰的信息层级重新整理 macOS 原生界面。左侧功能栏底部增加“整体设置”，可在阅读、Markdown 可视化和 Markdown 源码三套独立设置间切换。顶部工具按当前焦点区域显示：阅读时保留翻页、缩放和阅读样式，编辑笔记时保留排版、语法、源码显示和保存，避免两套工具同时挤在一行。

顶部原有“关闭原文”和“关闭笔记”合并为当前区域的关闭按钮，提示中明确关闭对象及未保存处理。侧栏、布局切换、分栏放大和主要快捷按钮补齐原生悬停提示及辅助功能名称。0.7.30 的阅读、编辑、文件转换和保存逻辑保持不变，首次启动导入 0.7.30 的设置。

# Markdown Studio Visual 0.7.30

阅读区新增 Word `.docx`、`.doc` 和苹果 `.pages` 的 macOS 原格式只读预览，不转换为 Markdown，不编辑原文。WPS 专有 `.wps` 文件明确提示暂不支持。Office/Pages 文件接入关闭原文、配套笔记与最近使用组合。优先生成缓存 PDF 供分页阅读（原文件不改写），支持 25%–500% 缩放和原文文字选择复制；Word 显式分页符保留，DOCX 读取纸张尺寸与页边距。自动分页、复杂分节、页眉页脚和缺失字体可能与原软件有差异；无法生成分页副本时明确提示并退回系统原格式预览。

新增“切换显示 / 并排显示”布局按钮。切换显示时，原文和笔记通过“阅读原文 / Markdown 笔记”按钮占满工作区，并保留视图实例；笔记内部继续支持可视化与源码切换。纯 Markdown 文件在此布局下切换可视化编辑和源码编辑。`Cmd+Shift+R` 在切换布局中切换阅读与编辑区域，在并排布局中只切换焦点；`Cmd+R` 仍切换 Markdown 可视化与源码。切换前提交并保存已修改的笔记。首次启动导入上一版的独立样式和最近使用设置。

修复 Word/Pages 工作区中 Markdown 可视化与源码面板“满屏/还原”状态未生效的问题，还原时保留分屏尺寸。

修复分屏控件自任代理引起的菜单验证递归和栈溢出；可视化与源码编辑器采用各自的撤销记录，切换文件及重建可视化页面时清理失效的撤销目标。

# Markdown Studio Visual 0.7.9

- 加粗、下划线等行内格式的相邻文字保持在原来的行或段落中，只有实际段落节点和换行节点才写入换行；修复渲染后 `br` 附带的 HTML 换行被重复写回的问题。

源码与可视化编辑模式的插入光标颜色调得更柔和。光标实际宽高仍由 macOS、WebKit 和字体度量控制。

# Markdown Studio Visual 0.7.5

修复可视化编辑与 Markdown 源码往返切换时的段落拆分：WebKit 在可视化编辑区生成的同级 `div` 现在按单换行序列化，不再被误写成空行分隔的多个 Markdown 段落；真正的段落仍保留空行，嵌入在这些行中的粗体等行内样式也会保留。新增 WebKit 回归测试覆盖截图中的分段文本。

这是 macOS 的独立试验版本，可与原来的 Markdown Studio 并存。双击打开 Markdown 文件后，原“预览”工作区现在可以直接点击正文编辑。右侧阅读笔记默认使用同一个可视化编辑区；工具栏的“语法”按钮提供标题、加粗、斜体、下划线、列表、引用、分隔线、图片和表格等操作。切到 Markdown 源码后，同一位置会显示“MD 预览”按钮。`⌘R` 可在可视化和源码之间双向切换，`⌘S` 保存回当前 `.md` 文件。

在可视化笔记与 Markdown 源码之间切换时，工作区会恢复到对应内容的位置；仅切换而未改动源码时，可视化视图会恢复原滚动高度。两个编辑区都允许将末尾文字向上滚动约半屏，不必在文件末尾添加空白行。

可视化编辑只将实际修改的区块写回 Markdown，未修改区块保持原文。对原始 HTML 和脚注等无法可靠往返转换的区块，请切换到源码模式编辑。复杂表格排版、嵌套结构和第三方 Markdown 扩展在可视化模式中仍建议先用文件副本核对保存结果。
