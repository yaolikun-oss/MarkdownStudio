# Markdown Studio 0.8.26 使用手册

本手册说明原生 macOS 版 Markdown Studio 0.8.26 的工作方式、主要功能、文件关系和当前限制。界面会根据当前任务隐藏无关工具，因此使用时应先确认右侧哪个标签获得了焦点。

## 1. 产品定位

Markdown Studio 面向“阅读资料并持续形成笔记”的工作过程。一个 Workspace 对应一本书或一个学习主题，其中可以同时保存：

- EPUB、PDF、MOBI、AZW、AZW3、Word、Pages 等阅读资料；
- 多份 Markdown 笔记及其图片附件；
- 多个网页标签、常用网站和长期网页收藏；
- 阅读位置、章节关联、界面排布和文件关系。

Workspace 是一个主题工程，不要求一本 EPUB 单独对应一个工程。一个工程中可以导入多本书，再为其中任意一本按需创建配套 Markdown 笔记。

## 2. 第一次启动

没有打开工程或文件时，“开始”面板只显示三个主要入口：

1. **打开文件**：立即阅读一个文件；如果当前已有 Workspace，会按导入流程处理。
2. **新建 Workspace**：为一个主题建立工程文件夹和 `.mdworkspace` 管理文件。
3. **打开 Workspace**：继续已有主题工程。

网页收藏可以在没有 Workspace 时单独查看。其余目录和管理按钮只有进入相应工作阶段后才出现。

## 3. Workspace 与文件管理

### 3.1 建议的工程结构

一个主题工程通常包含：

```text
主题工程/
├── 阅读资料/
├── 笔记/
│   ├── 主笔记.md
│   └── 书籍笔记/
├── 资源或其他自建目录/
└── 主题工程.mdworkspace
```

“主笔记”适合记录主题目标、研究范围、总目录和跨资料结论；“书籍笔记”保存与具体原书对应的笔记。

### 3.2 导入与临时打开

- **导入到工程**：把外部资料复制到 Workspace，再阅读工程中的副本。这样移动整个工程时，资料和笔记仍保持关系。
- **临时打开**：直接查看外部文件，不复制到当前工程，适合只读检查。
- 在资源管理器中右击文件夹，可把外部文件导入指定目录。
- 资源管理器右击文件可执行打开、在 Finder 中显示或移到废纸篓等操作。删除属于实际文件操作，会要求确认。

### 3.3 保存与重新打开

`.mdworkspace` 保存工程根目录、单独文件引用、标签布局、阅读资料与笔记关系及章节链接。重新打开 Workspace 后，程序会检查引用是否仍存在；缺失文件会被报告，而不是静默替换为其他文件。

关闭 Workspace 前会检查当前 Markdown 和可编辑原书是否存在未保存修改。

## 4. 左侧活动栏与上下文侧栏

最左侧活动栏提供：

- **文件**：开始页或 Workspace 资源管理器；
- **阅读**：当前 EPUB、PDF、Office 或网页的目录；
- **Markdown**：当前笔记的文件层级和标题目录；
- **网页收藏**：用于长期保存文章、博客和学习网页；
- **键盘**：打开分类快捷键面板；
- **设置**：打开阅读、Markdown 可视化和 Markdown 源码的独立样式设置。

侧栏跟随右侧获得焦点的标签变化。阅读原文时显示原书目录，编辑笔记时显示笔记目录。手动选择其他侧栏面板不会改变右侧文档。

## 5. 多文档标签、分屏和停靠

### 5.1 标签

EPUB、PDF、Office 文档、网页、Markdown 可视化和 Markdown 源码都可以成为独立标签。同一 Markdown 文件的可视化与源码是两个视图，共享同一份文件内容。

长文件名会在标签中间截断；悬停可以查看完整名称。

### 5.2 拖动与分屏

- 拖到现有标签栏：加入该区域，成为另一个标签；
- 拖到内容区左、右、上、下边缘：建立对应方向的分屏；
- 拖出主窗口：形成独立窗口；
- 独立窗口可重新停靠回主工作区；
- 工具栏提供全部合并、左右并排和上下并排的快捷排布。

关闭一个标签只关闭该视图，不等于删除磁盘文件。关闭有未保存内容的文档会先询问。

### 5.3 标签右键菜单

阅读资料标签的右键菜单包括：

- 创建或打开对应 Markdown 笔记；
- 向左、右、上、下拆分；
- 移到新窗口；
- 关闭标签。

“创建/打开对应笔记”直接绑定被右击的阅读资料，多本 EPUB 同时打开时不根据其他标签的残留焦点推断。

## 6. EPUB 与电子书阅读

### 6.1 阅读方式

EPUB 章节内部采用连续上下滚动；左右方向键切换阅读顺序中的上一章和下一章。点击左侧目录会跳到对应章节或小节。

工具栏可以调整阅读宽度、字体大小和样式。阅读位置按书籍保存，下次打开可恢复。

### 6.2 支持格式

- EPUB 文件；
- 已解包的 EPUB 文件夹；
- MOBI、AZW、AZW3：需要本机安装 calibre，程序转换到私有 EPUB 缓存后阅读；
- 带 DRM 的电子书、AZW4 和 KFX 当前不支持。

转换和解析不会改写原始电子书。可编辑 EPUB 的保存会输出新的 EPUB 文件。

### 6.3 EPUB 注释

选中原文后可以添加高亮、下划线和文字注释。注释保存在独立阅读数据库中，不写回原书。注释列表可以跳回原文位置，也可以修改或删除注释。

## 7. PDF、Word 与 Pages 阅读

### 7.1 PDF

- 连续滚动显示；
- 使用 PDF 自带层级目录，没有目录时显示页码列表；
- 支持页码跳转、上一页和下一页；
- 支持适合页宽、适合页高和最佳显示；
- 可以选取并复制 PDF 中已有的文本；
- 密码保护 PDF 会要求输入密码；
- 扫描页可以显示，但程序本身不提供 OCR。

### 7.2 Word 与 Pages

Word 和 Pages 只用于阅读，不修改原文。显示依赖 macOS 可用的系统预览能力，尽量保留原文分页和排版，并支持缩放和文字选择；复杂文档的还原程度可能受系统预览格式限制。

## 8. 创建和使用 Markdown 笔记

### 8.1 为当前原书创建笔记

有三种入口：

1. 右击目标原书标签，选择“创建对应 Markdown 笔记”；
2. 让目标原书获得焦点，进入左侧 Markdown 面板，点击创建按钮；
3. 打开电子书时，在方式选择中直接选择写配套笔记。

多本原书同时打开时，优先使用标签右键入口，因为它明确绑定被右击的那本书。已有笔记时，右键菜单自动改为“打开对应 Markdown 笔记”。

### 8.2 可视化编辑和源码编辑

- 可视化编辑用于接近最终排版的写作；
- 源码编辑显示 Markdown 标记、行号和可选语法着色；
- 两个视图共享同一文档会话；
- 切换视图时保存选区、光标和滚动位置；
- `⌘S` 显式保存；关闭或切换未保存文件时会询问。

源码语法着色可以关闭，以降低超长文档连续输入时的排版负担。

### 8.3 粘贴和资源

- 粘贴普通文本时清除外部富文本样式，按当前 Markdown 样式显示；
- 粘贴图片或使用插入图片命令时，图片复制到与笔记相邻的 `<笔记名>.assets` 目录，并插入相对链接；
- 从 Excel 或 Numbers 复制的单元格可以转换为 Markdown 表格，但不保留合并单元格和表格外观。

### 8.4 子笔记与 Markdown 文件引用

可视化编辑器支持通过斜杠命令插入标题、列表、引用、代码、表格、公式、分隔线、图片和子笔记等区块。

子笔记以一个完整文件区块显示，点击可进入子笔记，后退可返回原笔记。删除子笔记区块或从笔记树右键删除时会处理其对应文件，并在危险操作前确认。

普通 Markdown 文件之间可以使用相对链接引用，例如：

```markdown
[查看概念说明](概念说明.md)
```

点击链接可在工作区中打开目标笔记，并可使用笔记前进、后退和向上导航。

## 9. 原文章节与笔记标题关联

### 9.1 建立关联

1. 打开 EPUB 原文和对应 Markdown 笔记；
2. 在原书目录中选择具体章节或小节；
3. 在 Markdown 中把光标放在目标标题；
4. 执行“关联当前原文章节与当前笔记标题”。

每一条 EPUB 目录行拥有独立身份。即使多个目录项指向同一 XHTML 页面，也能分别关联。

### 9.2 双向跳转和重新关联

- 原书目录中的链接按钮可跳到笔记标题；
- 笔记标题旁的反向入口可跳回原文章节；
- 关联错误时可以重新选择标题并建立关联，只更新当前目录行；
- 新建第二条链接不会覆盖已经存在的其他章节链接；
- 可以解除当前章节关联；
- “关联跟随”关闭时只暂停自动跳转，不删除任何关系。

## 10. 网页阅读、常用网站与网页收藏

### 10.1 网页标签

输入网址时可以省略 `http://` 或 `https://`。输入普通搜索词时使用搜索方式打开。每个网页标签保留自己的历史和缩放状态。

网页选中文字可以剪藏到 Markdown，尽量保留标题、列表、链接、强调和表格，并附上来源地址。画布文本、跨域框架或禁止选取的网页可能无法剪藏。

### 10.2 两类收藏的区别

- **工作区常用网站**：ChatGPT、Gemini 等经常打开的服务快捷方式，位于工作区工具区域；
- **网页收藏**：需要长期保存的文章、博客、MOOC 页面，位于左侧“网页收藏”面板，可记录名称和备注。

两者用途和数据保持独立。

## 11. 样式设置

阅读、Markdown 可视化和 Markdown 源码使用三套独立设置，互不覆盖。可以分别调整：

- 内容宽度、背景色和正文颜色；
- 正文字体、字号、行距和段落间距；
- H1–H6 各自的字体、字号、粗细和颜色；
- 加粗文字样式；
- 目录层级颜色；
- EPUB 注释字体和颜色。

Markdown 默认标题尺寸为 H1 52px、H2 40px、H3 36px、H4 28px、H5 24px、H6 20px，加粗文字为 18px。H1 默认不显示下分隔线，H2 和 H3 显示分隔线。

样式设置只影响显示，不改写 Markdown 源文件。

## 12. 快捷键提示

点击左下角活动栏中的键盘图标，可以打开按“文件、视图、阅读、网页、关联和 Markdown 语法”分类的快捷键面板。也可以按 `⌘/` 打开。面板会提醒快捷键作用于当前获得焦点的区域。

## 13. 数据与安全边界

- 导入工程时复制资料，原始外部文件保留；
- Markdown 只有保存后才写入磁盘；
- EPUB 注释和阅读位置保存在独立阅读数据目录；
- Markdown 预览禁用 JavaScript；
- EPUB 内容在临时 WebView 中经过清理，并使用受限内容安全策略；
- 关闭标签不删除文件；资源管理器的删除命令才会移动真实文件到废纸篓；
- 当前预览安装包使用临时签名，不等于 Apple Developer ID 公证版本。

## 14. 已知限制

- DRM 电子书无法读取；
- PDF 扫描文字没有 OCR；
- Word 和 Pages 的复杂排版受 macOS 系统预览能力限制；
- 网页阅读不是完整浏览器，不提供扩展和下载管理；
- 某些网页无法提供可剪藏文本；
- 将 Workspace 移到另一台电脑时，应整体移动工程文件夹以及笔记的 `.assets` 目录；
- 独立窗口、复杂分屏和大量超长文档会增加内存占用，完成阶段性工作后可关闭不用的标签。

## 15. 推荐工作流程

1. 为学习主题新建 Workspace；
2. 把 EPUB、PDF 等资料导入“阅读资料”或自建目录；
3. 先阅读，不必立即创建所有笔记；
4. 需要记录时，右击目标原书标签创建对应笔记；
5. 使用主笔记汇总跨书结论，使用书籍笔记记录单本内容；
6. 对重要原文章节和笔记标题建立显式关联；
7. 用网页标签临时检索，用常用网站快速进入服务，用网页收藏保存长期资料；
8. 阶段结束后保存文档和 Workspace，关闭不再使用的标签。
