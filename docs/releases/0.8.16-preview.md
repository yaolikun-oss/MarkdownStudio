# Markdown Studio for macOS 0.8.16 Preview

## 版本定位

0.8.16 是原生 macOS 多文档工作区改造后的冻结基线。它把一本书或一个学习主题视为一个 Workspace 工程；工程可以包含多本阅读资料、多份 Markdown 笔记、附件和网页标签，而不是强制让一本 EPUB 对应一个独立工程。

本版本也是“Markdown 笔记章节与 EPUB 章节关联”开发前的回退点。

## 主要能力

### Workspace 工程

- 使用 `.mdworkspace` 文件保存工程文件夹、独立文件、标签和分屏布局。
- 工程目录默认包含“阅读资料”“笔记”和“附件”。
- 外部 EPUB、PDF、Word、Pages 等资料可以复制并校验后加入工程。
- 每份阅读资料可以拥有自己的配套 Markdown 笔记；工程主笔记用于记录学习目标、资料关系和综合结论。
- 左侧文件树用于浏览同一主题工程中的文件，文件可通过标签在工作区打开。

### 多文档标签与布局

- EPUB、PDF、网页、Markdown 可视化编辑和 Markdown 源码编辑可以作为工作区标签使用。
- 标签可以合并到同一标签栏，也可以向上、下、左、右拆分为不同区域。
- 支持常用的左右、上下及多区域快捷排布。
- 当前标签获得焦点时，左侧栏会自动切换到对应内容：阅读资料显示原文目录，Markdown 显示笔记层级。

### EPUB 阅读

- EPUB 采用章节内连续上下滚动，左右方向键切换上一章或下一章。
- 支持目录跳转、阅读宽度、字号、字体、颜色和行距设置。
- 阅读资料和 Markdown 笔记可以切换显示或并排显示。
- 隐藏标签不会抢占当前 EPUB 的键盘焦点。
- 0.8.16 将 EPUB 解压和目录解析移到后台，并让目录与阅读视图复用同一解析结果，避免同一本书重复解压。
- 同一会话再次打开同一本 EPUB 时会复用已经解析的文档。

### Markdown 笔记

- 支持可视化编辑、源码编辑和预览。
- 源码编辑具有行号、可选语法着色和独立样式设置。
- 可视化和源码标签切换时保留各自的工作区焦点和目录关系。
- 支持 Markdown 文件之间的引用链接、子笔记和工程内相对路径。
- 支持标题、强调、下划线、列表、表格、图片和常用语法快捷键。

### 其他阅读内容

- PDF 使用 PDFKit 阅读，支持连续滚动、目录、文字选择、缩放和适合宽度／高度／最佳显示。
- Word、Pages 等文档仅用于阅读，保留系统能够解释的原始排版。
- 网页标签用于临时查询和交互；左侧网页收藏用于长期保存学习资料，两者用途分开。

## 0.8.16 的重点修复

- 修复工作区内容获得焦点后，左侧目录没有跟随切换的问题。
- 修复多个同类标签存在时错误激活第一个标签的问题。
- 修复隐藏 EPUB 标签抢占方向键目标的问题。
- 为 WebKit 内的 EPUB 左右键增加页面内部导航兜底。
- EPUB 首次解析不再占用界面线程。
- 避免主工作区和阅读组件对同一本 EPUB 进行两次解压和解析。
- 保留最近工作区恢复、配套笔记打开和取消后台任务的正确关系。

## 已验证内容

- 生成的应用同时包含 Apple Silicon 和 Intel 架构。
- 应用签名完整性检查通过。

## 当前限制

- EPUB 首次从工程外导入时仍需复制并逐字节校验；这是资料安全流程，所需时间取决于文件大小和磁盘速度。0.8.16 保证该过程在后台进行，但不能让首次导入与缓存打开耗时完全相同。
- 某些图片密集、字体较多或章节结构异常的 EPUB，WebKit 首屏排版仍可能比纯文本 EPUB 慢。
- Word 和 Pages 只提供阅读，不提供原格式编辑。
- WPS 专有 `.wps` 格式暂不支持。
- EPUB 与 Markdown 章节尚未建立持久的双向绑定；这是下一阶段功能。

## 下一阶段：章节关联

计划在 Markdown 标题附近保存不可见的 EPUB 章节标识，记录工程内相对书籍路径、书籍指纹、spine 地址和章节锚点。目标包括：

- 从 EPUB 章节绑定到已有或新建的 Markdown 标题。
- 点击 EPUB 目录时定位对应笔记章节。
- 从笔记标题跳回 EPUB 原文章节。
- 通过 `/chapter` 插入当前阅读章节链接。
- 提供可关闭的章节跟随模式。
- EPUB 被替换或章节地址变化时明确提示绑定失效，避免静默跳错。
