# Markdown Studio for macOS 0.8.17 Preview

## EPUB 与 Markdown 章节关联

0.8.17 在 0.8.16 多文档工作区基础上加入 EPUB 原文章节与 Markdown 标题的显式关联。关联属于 Workspace 工程数据，不会写进 EPUB，也不会依赖容易变化的页码。

### 建立关联

1. 在工作区中打开 EPUB 和需要关联的 Markdown 笔记。
2. 将笔记光标放在目标标题内，或在左侧笔记目录中找到目标标题。
3. 使用菜单“章节关联 → 关联当前原文章节与当前笔记标题”，快捷键为 `⌥⌘L`。
4. 也可以在 EPUB 目录或 Markdown 目录中右击对应条目建立关联。
5. 在可视化编辑器标题下输入 `/chapter`，可以按实际输入位置关联上方最近的标题。

关联后，Markdown 中会增加形如 `<!-- mdstudio-chapter-link:… -->` 的内部标记。它在可视化笔记中不可见，用于在标题改名或前面增删内容后继续定位。源码模式可以看到并删除该标记；删除后应用会明确提示关联失效，不会猜测并跳到其他标题。

### 双向跳转

- EPUB 目录中已关联的章节显示链条图标，点击后打开并定位对应笔记标题。
- Markdown 目录中已关联的标题显示链条图标，点击后回到对应 EPUB 章节和目录锚点。
- 菜单“章节关联”也提供两个方向的跳转和解除关联。
- “章节自动跟随”开启时，已经同时打开的原文和笔记会相互跟随；关闭后只执行用户明确点击的跳转。

### 数据与失效保护

- 每条关联记录原书、原书内容指纹、EPUB `chapterHref`、目录 fragment、笔记文件和笔记标记。
- 同一 Workspace 可包含多本 EPUB；配套笔记优先关联到它所属的原书，避免多书并存时绑错。
- 原书被替换、章节地址改变、笔记文件丢失或内部标记被删除时，跳转停止并提示重新关联。
- 旧版 `.mdworkspace` 不含章节关联字段时仍可直接打开。

## 当前边界

- 章节关联只在 Workspace 工程内提供；临时打开、未加入工程的文件不会建立持久关联。
- 自动跟随只移动已经打开的另一侧文档。它不会为了跟随而主动打开隐藏文件或抢占当前输入焦点。
- 原书首次进行关联时需要在后台计算内容指纹。大文件会需要一些时间，但不会修改原书。
