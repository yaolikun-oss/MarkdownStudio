# Markdown Studio for macOS 0.8.18 Preview

## 章节关联定位修复

0.8.18 修复 EPUB 章节与 Markdown 标题建立关联时，多个章节可能全部关联到笔记第一个标题的问题。

问题原因是多文档工作区中的 Markdown 编辑器将视窗顶部行保存在自己的标签内部，而章节关联仍读取主窗口残留的旧行号；旧值通常为第 1 行。修复后：

- 每份 Markdown 标签分别记录自己的当前位置，不再共用主窗口旧行号。
- 源码编辑按照原生光标选择范围计算实际行。
- 可视化编辑按照 Web 编辑器保存的选择范围计算实际行。
- 只有无法取得光标或选择范围时，才使用该文档最后记录的视窗行。
- 通过关联跳转定位 Markdown 后，会同步更新该文档的位置记录。

0.8.17 中已经绑错的记录不会自动猜测新的目标，需在 0.8.18 中解除后重新关联，以免静默修改用户原有关系。
