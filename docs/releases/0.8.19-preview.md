# Markdown Studio for macOS 0.8.19 Preview

## 多条章节关联修复

0.8.19 修复连续建立第二条 EPUB 与 Markdown 关联时，第一条关联消失、只保留当前一条的问题。

### 修复内容

- 左侧 Markdown 目录选择的标题使用独立、稳定的标题身份，不再被编辑器旧光标覆盖。
- 标题身份由标题层级、标题文字和同名标题序号组成；前文插入关联标记导致行号顺延时，后面的标题仍能正确定位。
- 新关联只替换同一个原文章节目标或同一个笔记标题锚点，不再删除无关关联。
- EPUB 关联键同时包含章节文件和页内锚点，支持同一 XHTML 页面中的多个目录小节分别关联。
- 正向跟随会把页内锚点一同传递给笔记查找，避免同页不同小节都跳到第一条关联。
- 工作区保存和重新打开后，多条关联会完整保留。

### 长文档回归

使用 1,200 个 Markdown 标题建立多条关联，覆盖：

- 连续新增关联并检查全部旧记录仍存在。
- 同一 EPUB 页面内多个不同锚点的精确匹配。
- EPUB 到 Markdown 的正向查找。
- Markdown 到 EPUB 的反向查找。
- 前文插入隐藏锚点后，后文标题行号变化的重定位。
- 80 条关联保存到工作区并重新读取。
- Markdown 锚点缺失或 EPUB 页内锚点变化时停止跳转，不猜测错误目标。

0.8.18 及以前已经被覆盖或绑错的关联无法从现有工作区自动推断回来，需要在 0.8.19 中重新建立。
