# Markdown Studio for macOS 0.8.20 Preview

## 打开流程与原书关联修复

0.8.20 把首次打开、工程浏览、阅读资料和 Markdown 笔记分成明确状态，并修复 EPUB 首次显示慢、关闭原文后目录残留及重复关联覆盖旧记录的问题。

### 打开与创建流程

- 未打开工程或文件时，顶部和正文只保留一个“打开”入口；左侧仍可进入网页收藏。
- “打开”统一接受 EPUB、PDF、Word、Pages、Markdown 和 `.mdworkspace`，后续功能按文件类型出现。
- 工程打开后才显示新建工程、添加文件夹、导入文件、关闭文件等管理按钮。
- 导入阅读资料不再暗中创建配套书籍笔记。
- 选中一本尚无配套笔记的原书时，Markdown 侧栏显示“创建此资料的 Markdown 笔记”。
- 工程的“主笔记”继续用于主题目标、资料关系和综合结论；每本书的配套笔记由用户按需要创建。

### EPUB 与 Markdown 关联

- 同一段原文可以被多个 Markdown 标题引用，新关联不会删除旧关联。
- 移动同一个笔记标题的关联时，只更新该标题自己的记录。
- 长文档、多条关联、保存重开及正反向定位继续使用稳定锚点。

### EPUB 打开与关闭

- 隐藏的可视化编辑器不再覆盖当前编辑器的保存回调，点击原文标签不再等待错误的隐藏编辑器。
- 工作区恢复时，正在后台解析的 EPUB 不会被当成加载失败而提前移除。
- 关闭当前原文标签后立即激活剩余标签；没有可见原文时，左侧原书目录同步消失。

### 验证

- 工作区状态、标签恢复与停靠：14 项。
- 长文档章节关联：7 项。
- 可视化编辑与即时切源码：33 项。
- 新的空启动和按需显示流程：3 项。
- 使用真实《艾希曼在耶路撒冷》工程副本做后台解析，首次约 0.08 秒，随后约 0.03 秒；没有修改用户资料。

完整测试中的两个 AppKit 行号截图断言仍受无前台窗口环境影响；它们在修改前基线同样失败，长文档光标、方向键与选区回归均通过。
