# Markdown Studio for macOS 0.8.21 Preview

## EPUB 目录关联稳定性修复

0.8.21 修复同一 EPUB 页面包含多个目录项时，新增或纠正一条关联会让前一条关联消失的问题。

### 关联规则

- 每一条 EPUB 目录行拥有独立身份，即使“七”和“八”实际指向同一个 XHTML 文件，也不会再互相覆盖。
- 一条目录行当前只指向一个 Markdown 标题；选错标题后重新关联，只替换这一条目录行的目标。
- 不同目录行可以指向同一个 Markdown 标题。
- 一个 Markdown 标题可以关联多处原文；目录中的计数菜单可分别打开或解除每一处关联。
- 解除其中一条关联时，仍被其他关联使用的 Markdown 锚点会保留。

### 工作区保存修复

- 统一解包 EPUB 的文件式和目录式 URL，避免同一路径因尾斜杠被识别成两本书。
- 打开旧工作区时合并重复的“原书—配套笔记”记录，并优先保留实际存在的笔记文件。
- 旧版本没有目录行身份字段的章节关联仍可读取。
