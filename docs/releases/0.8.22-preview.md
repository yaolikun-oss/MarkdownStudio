# Markdown Studio for macOS 0.8.22 Preview

## 流程化侧栏与关联跟随开关

0.8.22 重新整理左侧活动栏和面板，让侧栏展示当前步骤真正需要的内容。

### 空启动

- 没有工程和文件时，不显示工程管理按钮组。
- “开始”面板只提供打开文件、新建 Workspace、打开 Workspace 和最近工程。
- 网页收藏仍可独立进入，不要求先创建工程。

### 工程与上下文面板

- 工程管理操作只出现在“资源管理器”，不再占据原书目录、笔记目录和网页收藏的顶部。
- 已进入工程后，资源管理器直接展示工程树；最近工程不再长期挤占文件列表。
- 右侧焦点进入 EPUB、PDF、Office 或网页时，左侧自动显示对应阅读目录。
- 焦点进入 Markdown 源码或可视化编辑时，左侧自动显示笔记层级和标题目录。
- 原文已打开但还没有配套笔记时，笔记面板只显示创建笔记入口。
- 每个面板只保留当前可用的操作，例如关联跟随、展开笔记目录或打开网页。
- 原书目录和笔记目录标题不再放置容易误解的 `×`；单个文件由标签栏关闭。
- “关闭工作区”作为带文字的独立操作放在资源管理器标题下方，关闭前统一检查所有未保存笔记和原书修改。

### 关联跟随

- EPUB 与 Markdown 同时可用时，工具栏显示“关联跟随”按钮。
- 关闭后只暂停自动双向跳转，已经建立的链接完整保留。
- 暂停期间仍可手动点击链接跳转，也可以随时重新开启自动跟随。
- 左侧原书目录和笔记目录顶部同步提供紧凑开关，并清楚显示开启或暂停状态。

### 验证

- 空启动、只有网页、空工程、只打开原书、原书加笔记以及多标签焦点切换状态均纳入回归。
- 工作区入口、标签停靠、文档会话和章节关联专项 33 项通过。
- 使用隔离的 EPUB、Markdown 和 Workspace 做真实界面复测，确认原书与笔记焦点会切换对应目录，关联跟随开关在两侧保持同一状态，资源管理器不会改变右侧工具目标。
