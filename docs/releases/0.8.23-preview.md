# Markdown Studio for macOS 0.8.23 Preview

## 本版修复

- 多本 EPUB 同时打开时，创建配套 Markdown 笔记以最后真正获得焦点的阅读标签为准；切换到左侧目录或右侧笔记后仍保留这一明确对象。
- 已关闭的旧阅读标签不会被继续用于新建笔记。无法确认当前 EPUB 时停止创建，避免静默关联到另一本文档。
- 多根目录 Workspace 会把配套笔记建立在实际包含当前 EPUB 的工程根目录内。
- 如果目标笔记文件名已经存在但尚未建立配套关系，会生成带序号的新文件，避免把原有 Markdown 误认成当前书的笔记。
- EPUB 目录行采用精确身份查询。两条目录即使指向同一个 XHTML 页面，未关联的一条也不会显示或继承另一条的链接。
- 从目录点击、章节跟随、正向跳到笔记和反向跳回原文时都会携带具体目录行身份。

## 验证

- 两本 EPUB、两个编辑组和一个 Markdown 标签之间反复切换，创建目标始终跟随获得焦点的阅读标签。
- 相同目录结构的两本 EPUB 保留彼此独立的关联。
- 同一 EPUB 中两条目录指向同一 XHTML 时分别关联、纠正其中一条和解除其中一条，另一条保持不变。
- 1200 个标题的长 Markdown 文档连续建立多条关联，已建立链接保持存在；保存并重新打开 Workspace 后仍可恢复。
- 针对工作区、目录关联与创建流程的 34 项测试通过。

## 行为边界

如果多个 EPUB 同时可见、当前活动标签是 Markdown，并且本次启动后还没有点过任何阅读标签，应用不会猜测要给哪一本书创建配套笔记。先点一下目标 EPUB，再创建笔记即可。这项限制用于防止把笔记静默配错书。
