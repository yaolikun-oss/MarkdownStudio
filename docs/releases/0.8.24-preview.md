# Markdown Studio for macOS 0.8.24 Preview

## 本版修复

- 多本 EPUB 同时打开时，点击“创建此资料的 Markdown 笔记”会把按钮所对应的 EPUB 和新建 Markdown 作为一次不可拆分的操作。
- 创建函数直接打开本次实际创建或找到的 Markdown 文件，不再依据全局阅读焦点进行第二次关系查询。
- 即使 EPUB WebView 的延迟焦点回调在快速切换标签、打开 Markdown 侧栏期间到达，也不会把刚创建的笔记切回上一本文档。
- 创建完成后会重新固定本次 EPUB 为最近阅读对象，后续章节关联继续使用正确原书。

## 验证

- 在同一工程同时打开《思考，快与慢》《被禁锢的头脑》《疯传》等多本 EPUB。
- 聚焦《疯传》，打开 Markdown 侧栏并实际点击创建；生成并打开的是《疯传》的独立 Markdown，左侧笔记层级和工作区关系均指向《疯传》。
- 切换回已有配套笔记的《被禁锢的头脑》，左侧仍显示其自身笔记，不与《疯传》混用。
- 工作区布局与多 EPUB 焦点相关的 18 项测试通过。
