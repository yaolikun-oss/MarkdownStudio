# Markdown Studio for macOS 0.8.25 Preview

## 新增入口

- 右击 EPUB、PDF 等阅读资料的工作区标签，可直接创建对应 Markdown 笔记。
- 已经存在配套笔记时，同一位置显示“打开对应 Markdown 笔记”。
- Markdown、网页等非阅读标签不会显示这两个无关菜单项。

## 多资料安全性

- 右键命令直接使用被右击标签携带的阅读资料地址。
- 创建与打开均不依赖当前侧栏、最近焦点或其他 EPUB 的延迟回调。
- 因此在多本 EPUB 同时打开时，右击《疯传》只会处理《疯传》的配套笔记。

## 保留入口

左侧 Markdown 面板中的“创建此资料的 Markdown 笔记”继续保留，方便键盘和侧栏操作；标签右键菜单提供更直接的入口。
