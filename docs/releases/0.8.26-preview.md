# Markdown Studio for macOS 0.8.26 Preview

## 快捷键入口

- 左下活动栏新增键盘图标，任何工作阶段都可以打开快捷键速查。
- `⌘/` 也可以打开同一面板。
- 面板按文件、视图、阅读、布局、网页、章节关联、Markdown 格式和编辑分类。
- 对只在特定焦点生效的方向键和切换键注明适用范围。

## 文档

- 新增《Markdown Studio 0.8.26 使用手册》。
- 手册说明从新建 Workspace、导入资料、创建配套笔记到章节关联和网页剪藏的完整流程。
- 明确工作区常用网站与网页收藏、关闭标签与删除文件、导入与临时打开等容易混淆的边界。
- 记录文件落点、数据安全方式、当前格式限制和推荐工作流程。
