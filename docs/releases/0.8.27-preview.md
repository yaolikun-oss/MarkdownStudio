# Markdown Studio for macOS 0.8.27 Preview

## EPUB 方向键焦点修复

- 这不是 macOS 全局热键冲突。0.8.25 为防止 EPUB 抢走 Markdown 编辑器的左右键，要求 EPUB WebView 必须是原生键盘焦点。
- 多标签和跟随侧栏加入后，点击原书目录会把焦点留在目录；分屏时活动分组也可能仍是 Markdown，因此左右键被安全检查拒绝。
- 点击 EPUB 目录项时，现在会同时选中该 EPUB 所在标签和分组，并在完成章节定位后把原生焦点交回 EPUB WebView。
- 点击工具栏上一章、下一章或使用方向键翻章后，也会继续保持 EPUB 焦点。
- 单文件旧阅读布局补上独立焦点请求；多文档工作区使用被选中的具体 EPUB 标签，避免聚焦到另一本文档。
- 焦点位于 Markdown 源码或可视化编辑器时，左右键仍然只移动编辑光标，不会被 EPUB 拦截。

## 验证范围

- EPUB 原生方向键路由与显式焦点恢复测试。
- 多 EPUB 工作区焦点、标签、分屏和重复停靠回归测试。
- 真实界面依次验证：选择原书标签、点击左侧目录、按左右键连续翻章，再切回 Markdown 检查光标移动。
