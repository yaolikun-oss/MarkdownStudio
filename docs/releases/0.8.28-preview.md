# Markdown Studio for macOS 0.8.28 Preview

## EPUB 注释恢复

- 注释底层和旧版单文件阅读视图并未删除；多文档工作区的阅读标签曾把注释列表固定传为空数组，同时忽略原文选区与编辑、删除回调，导致已有注释和新增入口一起消失。
- 每个 EPUB 标签现在按书籍身份独立加载和保存高亮、下划线与文字备注，不会把多本书的注释混在一起。
- 工具栏恢复“添加注释”和“注释列表”按钮；选中文字后可添加注释，列表显示当前书的注释数量。
- `⇧⌘M` 添加注释、`⌥⌘M` 查看注释列表重新跟随当前获得焦点的 EPUB。
- 注释列表、原文内联提示及右键操作支持查看、修改、删除，并可跳回对应章节和标记位置。
- 关闭标签或切换书籍不会删除注释；删除工作区资源或关闭工程时只清理内存状态，持久注释仍保存在独立阅读数据库中。

## 验证范围

- 阅读数据库按书籍身份保存、加载、修改和删除注释。
- 多 EPUB 标签切换后，注释入口和列表跟随当前书籍。
- 从原书选择文字新增注释，重新打开后仍显示；列表跳转返回正确章节。
- EPUB 左右方向键和 Markdown 编辑器光标方向键回归检查。
