# Markdown Studio for macOS 0.8.29 Preview

## 修复

- EPUB 阅读标签获得工作区焦点后，左右方向键稳定切换上一章和下一章。
- 不再依赖 WebKit 内部内容视图是否被 AppKit 识别为第一响应者。
- Markdown 源码或可视化标签获得焦点时，阅读标签的方向键路由自动停用，不会抢走编辑器光标。
- 关闭 EPUB 注释、设置等弹出窗口后，焦点自动返回当前阅读区。

## 验证重点

- 多分屏时点击 EPUB 正文，再按左右键。
- 切换到 Markdown 源码后，左右键仍逐字移动光标。
- 从注释列表或注释编辑窗口返回后，左右键仍可切换 EPUB 章节。
