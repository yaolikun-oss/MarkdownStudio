# Markdown Studio Windows 0.2.0 预览版

这是独立的 Windows 实现，沿用 Mac 版“阅读原文 + Markdown 笔记”的工作方式。Mac 版 Swift 工程保持原状。

## 使用

1. 将 `MarkdownStudio-Windows-0.2.0-x64.zip` **完整解压**到一个文件夹。
2. 在 Windows 10/11 x64 上运行文件夹内的 `Markdown Studio.exe`。不要只复制 EXE，运行时需要旁边的资源文件。
3. 建议先“新建工程”或“打开工程”。一个 Workspace 对应一个学习主题；导入的原书会复制进工程的“阅读资料”，Markdown 放入“笔记”。

这是未签名的预览版；正式面向公众发行前仍需 Windows 原机验收与代码签名。当前构建在 Mac 上交叉打包，不能视为已经完成 Windows 原机测试。

## 功能

- 主题 Workspace：自动建立“阅读资料 / 笔记 / 网页”和主笔记；支持导入复制、重开工程、工程内文件树与右键移到回收站。
- 多文档标签：PDF、EPUB、Word、网页和 Markdown 可同时打开并在标签间切换，标签可单独关闭；阅读区与笔记区继续支持稳定的左右分屏。
- EPUB 备注：选择原文后可高亮或下划线、写备注、跳回原文、修改或删除；备注按原书路径保存在本机。
- PDF、EPUB、DOCX 只读阅读，文字选择与复制，缩放；PDF 保留原始页码，支持适宽、适高。EPUB 在当前章节内连续上下滚动，左右键切换上一节或下一节。
- Markdown 可视化编辑与 CodeMirror 源码编辑：行号、语法着色、可选空白与段落标记、语法工具菜单、搜索、撤销重做。
- 只打开 Markdown 时，可视化在左、源码在右；也可改为单区切换。
- 原文与笔记支持并排、按钮切换、单个面板满屏与还原。分屏比例保存在本机。
- 阅读、可视化、源码分别保存字号、行距等设置。PDF / Word 保持原排版，用缩放调整显示；EPUB 支持字体与行距调整。
- 独立关闭原文或笔记；未保存笔记有保存、放弃、取消提示。外部程序修改文件后会阻止覆盖并要求另存为。
- 自动保留未保存笔记恢复副本；恢复时作为未命名笔记打开，不直接覆盖磁盘文件。
- 可粘贴截图（PNG/JPEG/WebP），保存到笔记旁的 `.md-assets`。搬运笔记时请连同此目录一起移动；将笔记另存到其它文件夹时，也需要复制原来的相对图片目录。
- 可视化粘贴文字会清除外部格式。
- 网页阅读、地址栏导航、前进后退、收藏、将选中文字剪藏到笔记。网页在隔离的浏览器视图中显示。

## 文件格式边界

| 格式 | 当前行为 |
| --- | --- |
| MD / Markdown / UTF-8 TXT | 可编辑；保存时换行可能统一为 LF |
| PDF | 原始分页、可选择文字的文本层；扫描件没有文字层时不能直接复制文字，本版不提供 OCR |
| EPUB | 当前章节内连续上下滚动；目录和左右键按书脊顺序切换章节；遵循重排排版 |
| DOCX | 保留文本、表格、图片、页眉页脚和显式/已记录分页；复杂自动分页、特殊字体或复杂域不保证与 Word 完全一致 |
| DOC / Pages | 需已安装 LibreOffice，打开时生成只读 PDF 缓存并提示；无法转换时提示导出 PDF，不修改原件。Pages 文件夹包请先导出 PDF |
| MOBI / AZW / AZW3 | 需已安装 Calibre，打开时转换 EPUB 并提示；不支持解除 DRM |
| WPS | 暂不支持 |

包含脚注、任务列表、公式、YAML 元数据、引用式链接或自定义 HTML 的 Markdown，当前会停用可视化编辑并提示使用源码，避免未经支持的反向转换导致内容丢失。普通标题、列表、表格、链接、图片、粗体、下划线等可以可视化编辑。括号等标点位于粗体边界时，可能使用等价的 `<strong>` 标签，避免 `**` 被解析成普通字符。

PDF 文件上限 512 MB；DOCX/EPUB 阅读数据上限 128 MB；笔记 32 MB。字体以 Windows 实际安装为准。

## 快捷键（Windows）

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+O / Ctrl+Shift+O | 打开文件 / 文件夹 |
| Ctrl+N | 新建笔记 |
| Ctrl+S / Ctrl+Shift+S | 保存 / 另存为 |
| Ctrl+W | 关闭当前原文或笔记 |
| Ctrl+R | 切换可视化 / 源码 |
| Ctrl+Shift+R | 切换阅读 / 编辑；并排时移动焦点 |
| Ctrl+Shift+M | 当前面板满屏 / 还原 |
| Ctrl+Alt+L | 并排 / 切换显示 |
| Ctrl+F | 查找当前笔记 |
| Ctrl+= / Ctrl+- | 放大 / 缩小原文 |
| F11 | 窗口全屏 |
| 左右方向键 | EPUB 切换上一节 / 下一节；编辑器内保持正常光标移动 |
| Ctrl+Alt+M | 为当前 EPUB 选中文字添加备注 |
| Ctrl+Alt+Shift+M | 打开当前 EPUB 备注列表 |

## 构建

建议 Node.js 22 或更新的受支持 LTS，npm。运行：

```sh
npm ci
npm test
npm run build
npm run package:win
```

产物在 `release/`。Windows 上同样可以执行这些命令。本机用户设置、转换缓存和恢复副本保存在 Electron 的用户数据目录（通常为 `%APPDATA%/MarkdownStudioWindows`），不会写入原文文件。

开发：`npm run dev`。`npm run package:mac-qa` 仅用于在 Mac 上验证相同的 Electron/渲染器代码，不是向用户发布的 Mac 版本。

验证范围与待验收项目见 [QA.md](QA.md)。

## 0.1.3 样式与阅读工具

- 样式面板分别保存 EPUB 阅读、Markdown 可视化、Markdown 源码的设置，切换设置范围时会暂存当前修改，点击“应用”一起保存，“取消”全部放弃。
- 正文字体、字号、颜色、背景色、行距、内容宽度可独立调整；可视化与 EPUB 另有段距、对齐与标题设置。标题 1–6 各有自己的字号与颜色（默认 52/40/36/28/24/20px）。
- 源码维持统一字号和行高，分别调整六级标题与加粗的语法颜色，避免破坏行号、光标及键盘移动；关闭语法着色时显示正文颜色。PDF、Word 与网页使用原始版式和缩放，不套用 EPUB 字体样式。
- EPUB 宽度是内容最大宽度：阅读面板比设定宽度窄时会自动适应面板。设置覆盖已经显示与之后翻页的正文。
- “语法”菜单右侧提示实际支持的快捷键：Ctrl+B/I/U、Ctrl+Shift+X、Ctrl+Alt+0–6；Mac 测试壳对应 Cmd。其余语法通过菜单应用，没有虚构的快捷键。
- 网页支持直接输入 example.com、带路径或端口的网址，自动补 https://；明确输入 http:// 会保留。
- PDF 增加“最佳显示”：每次扫描当前页，主体扫描图按原图像素 / 当前屏幕倍率计算，普通矢量页使用完整页面比例。没有一个对所有 PDF 都适用的固定“最清晰比例”。暂不识别拼接扫描图作为一张完整扫描页。

## 0.1.4 EPUB 连续阅读

- EPUB 取消按屏幕分页，当前章节像网页一样连续上下滚动。
- 左右方向键和工具条箭头改为上一节、下一节，章节位置显示为当前书脊章节序号。
- 目录仍可直接进入指定章节或章节内锚点；恢复阅读时保留 EPUB CFI，旧版只保存章节序号的记录也会回到对应章节。

## 0.2.0 Workspace、多文档与 EPUB 备注

- 新建 Workspace 时生成主题目录、`.mdworkspace` 工程文件和主笔记；导入资料会复制到工程，不依赖原文件继续存在。
- 左侧工程树按“笔记 / 阅读资料 / 网页”分组；工程内文件可直接打开，右键删除会先确认并移到系统回收站。
- 已打开的阅读资料、网页和 Markdown 显示为标签，可切换、单独关闭；当前版本采用稳定的“阅读 + 笔记”双区，不宣称已经实现 VS Code 任意网格停靠或独立窗口回拖。
- EPUB 支持高亮、下划线和文字备注，提供跳转、修改、删除及重启恢复。
- 当前工程会在下次启动时恢复；0.2.0 暂不自动恢复上次全部已打开标签，文件仍可从工程树和最近使用中重新打开。
